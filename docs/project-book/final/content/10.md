# נספח א — הוראות התקנה והרצה

**דרישות:** Node.js בגרסה 20.12 ומעלה (המערכת פותחה ונבדקה בגרסה 22.21) ו-npm בגרסה 9 ומעלה. לא נדרש שירות נוסף.

**התקנה והרצה:**

```
npm install
npm run dev:full
```

הלקוח נגיש בכתובת `http://localhost:5173`, ושרת ה-API בכתובת `http://localhost:3001`. לאחר פתיחת הכתובת בדפדפן יש ליצור חשבון ולהשלים את שאלון ההיכרות.

Table: א.1 | פקודות ההרצה והבדיקה
Widths: 38,62
| פקודה | תפקיד |
|---|---|
| `npm run dev:full` | הלקוח והשרת יחד |
| `npm run dev` | הלקוח בלבד |
| `npm run dev:server` | שרת ה-API, עם טעינה מחדש אוטומטית |
| `npm run build` | בניית הלקוח לתיקיית `dist` |
| `npm run lint` | בדיקת קוד סטטית |
| `npm test` | בדיקות היחידה |
| `npm run test:integration` | בדיקות האינטגרציה מול שרת פעיל |

**הגדרות.** הגדרות השרת נקראות מהקובץ `.env.local` שבשורש הפרויקט, שאינו נכלל במאגר. שמות המשתנים מפורטים בקובץ `.env.example`: מפתח הגישה לשירות מודל השפה (רשות; בלעדיו המערכת פועלת במצב הדגמה, על קבלה קבועה), מפתח שירות הדוא"ל (רשות; לאיפוס סיסמה), כתובת השולח וכתובת היישום. אין לשמור ערך סודי במשתנה ששמו מתחיל ב-`VITE_`, משום שמשתנים אלה נכללים בקוד הנשלח לדפדפן. לאחר שינוי ההגדרות יש להפעיל מחדש את השרת.

**תוצרי ההגשה.** לפי הנחיות המכללה, לדוח מצורפים קוד המערכת, הדוח עצמו, המצגת וקובץ `README`. קובץ ה-`README` שבשורש המאגר כולל את ההוראות שלעיל באנגלית.

קוד הניסוי, התרחישים והתוצאות הגולמיות נמצאים במאגר, בתיקייה `docs/algorithm-audit/experiments`, ואינם חלק מקוד היישום.
