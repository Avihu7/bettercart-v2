# נספח א — חלוקת העבודה בין המגישים

פיתוח פרויקט **BetterCart** בוצע בשיתוף פעולה בין שני המגישים, תוך חלוקת תחומי אחריות והתייעצות משותפת לאורך שלבי העבודה.

**אביעד בניטה** – התמקד בתכנון ארכיטקטורת המערכת, בפיתוח ממשק המשתמש וחוויית השימוש, במימוש תהליכי העבודה המרכזיים, בשילוב רכיבי המערכת ובביצוע בדיקות ותיקוני באגים.

**נועם רף** – התמקד בפיתוח הלוגיקה העסקית והאלגוריתמית, בעבודה עם מסד הנתונים וקטלוג המוצרים, בתהליכי עיבוד הנתונים והתאמת המוצרים ובבדיקת תקינות התוצאות.

שני המגישים היו שותפים להגדרת הדרישות, לקבלת ההחלטות הטכנולוגיות, לפתרון בעיות מורכבות, לבדיקות המערכת ולגיבוש התוצר הסופי. העבודה המשותפת אפשרה שילוב של הרכיבים לכדי מערכת אחת שלמה ומתפקדת.

# נספח ב — הרצת המערכת וחומרים נלווים {nobreak}

המערכת דורשת Node.js בגרסה 20.12 ומעלה. להתקנה ולהרצה של הלקוח והשרת יחד:

```
npm install
npm run dev:full
```

ללא מפתח גישה למודל השפה המערכת פועלת במצב הדגמה, על קבלה קבועה. הוראות מלאות מופיעות בקובץ README שבמאגר הקוד. החומרים שאינם נכללים בגרסה זו של הדוח שמורים במאגר, תחת התיקייה docs: דוח ה-QA המלא וראיותיו, ביקורת האלגוריתמים ונתוני הניסוי, ומהדורה מורחבת של דוח זה, הכוללת את סכמת הנתונים, ממשק ה-API ופירוט התרחישים.
