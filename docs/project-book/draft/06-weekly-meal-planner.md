# פרק 6 — תכנון התפריט השבועי וולידציה

מתכנן התפריט מקבל את הסל, את הפרופיל ואת תקציב המזון, ומפיק תפריט לשבעה ימים. המתכנן דטרמיניסטי לחלוטין: אין בו קריאה למודל שפה, אין רכיב אקראי ואין גישה לרשת. אותו סל, אותו פרופיל ואותו תקציב מניבים תמיד אותו תפריט.

התהליך כולו הוא שרשרת של שבעה שלבים:

```
סל → קטלוג מוצרים פנימי (קבוצות מזון, תפקידי ארוחה)
   → ארוחות מועמדות
   → ניקוד וחיפוש (חמדני + מקומי), בארבע גרסאות משקלים
   → איזון מנות ליעדי התזונה
   → התאמה לתקציב
   → ולידציה ודירוג
   → בחירת השבוע הטוב ביותר ורשימת החלופות
```

## 6.1 מטרות המתכנן

### 6.1.1 מבנה התפריט

- **שבעה ימים בדיוק**, מיום ראשון עד שבת. המבנה קבוע ואינו תלוי בתדירות הקנייה של המשתמש.
- **ארבעה סוגי ארוחות ביום:** בוקר, צהריים, ערב וביניים — 28 משבצות בשבוע.
- **חלוקת הקלוריות היומית** בין הארוחות, כנקודת מוצא: בוקר 25%, צהריים 35%, ערב 27%, ביניים 13%.
- **ארוחה** היא רשימת מוצרים מהסל, לכל אחד כמות בגרמים, וכן שם ארוחה בעברית הנגזר ממרכיביה.

ארוחות הבוקר, הצהריים והערב הן חובה בכל יום; ארוחת הביניים היא רשות. תפריט שבאחד מימיו חסרה ארוחת חובה אינו נשמר (סעיף 6.7).

### 6.1.2 יעדי התזונה

היעדים שמולם נבנה התפריט מחושבים מהפרופיל, בנוסחאות הבאות.

**קצב חילוף חומרים בסיסי (BMR)**, בנוסחת Mifflin-St Jeor, כאשר W המשקל בק"ג, H הגובה בס"מ ו-A הגיל בשנים:

  BMR = 10·W + 6.25·H − 5·A + 5  (גברים)
  BMR = 10·W + 6.25·H − 5·A − 161  (נשים)

**הוצאת אנרגיה יומית (TDEE)** — מכפלת ה-BMR במקדם פעילות: 1.2, 1.375, 1.55, 1.725 או 1.9, לפי רמת הפעילות שבפרופיל.

**יעד קלורי יומי** — TDEE פחות 400 קק"ל לירידה במשקל, TDEE ועוד 400 קק"ל לעלייה, ו-TDEE לשמירה.

**יעד חלבון** — לפי משקל הגוף: בין 1.6 ל-2.0 גרם לק"ג לפי תדירות אימוני הכוח, ובין 1.8 ל-2.2 גרם לק"ג כאשר המטרה היא ירידה במשקל; לעולם לא מעל 2.2 גרם לק"ג.

**יעד שומן** — 30% מהקלוריות (25% לעלייה במשקל), מחולק ב-9 קק"ל לגרם.

**יעד פחמימות** — יתרת הקלוריות לאחר החלבון והשומן, מחולקת ב-4 קק"ל לגרם.

[VERIFY: יש לקבל מאביעד ונועם את המקורות שעליהם התבססו הנוסחאות והקבועים — נוסחת Mifflin-St Jeor, מקדמי הפעילות, הפרש 400 קק"ל, טווחי החלבון לק"ג וחלק השומן — ולצטטם. אין לצטט מקור שלא נעשה בו שימוש בפועל. בהיעדר מקור, הקבועים יוצגו כהחלטת תכן.]

היעדים הם הערכה כללית ואינם המלצה רפואית או דיאטנית אישית.

### 6.1.3 הדרישות מהתפריט

התפריט נדרש לקיים, לפי סדר חשיבות יורד:

1. **בטיחות:** רק מוצרים מהסל; ללא מוצר הסותר את התזונה או את האלרגיות; ללא בשר וחלב באותה ארוחה.
2. **ריאליזם:** ארוחות מקובלות ומנות בגודל סביר.
3. **תזונה:** עמידה ביעד הקלורי, ביעד החלבון וביעד השומן בכל יום.
4. **תקציב:** עלות שבועית בתוך תקציב המזון.
5. **גיוון:** במידה שהסל מאפשר.

## 6.2 קבוצות מזון וחוקי ארוחה

### 6.2.1 סיווג לקבוצות מזון

כל מוצר בסל מסווג לאחת מ-20 קבוצות מזון לפי שמו (וקבוצה נוספת, "אחר"). הסיווג נעשה מול רשימה סדורה של קבוצות, ולכל קבוצה רשימת מונחים; המוצר משויך לקבוצה הראשונה שאחד ממונחיה מופיע בשמו לאחר נרמול. הסדר נבחר כדי להכריע מקרים דו-משמעיים: "חלב שקדים" נבדק לפני אגוזים וחלב ומסווג כמשקה צמחי; "סרדינים בשמן" נבדק לפני שמן ומסווג כדג; "שעועית לבנה" נבדקת לפני הגבינות ואינה מזוהה כלבנה; ותבלינים מסווגים "אחר" כדי ש"פלפל שחור" לא ייחשב ירק.

הקבוצות: בשר ועוף, דגים, ביצים, קטניות, גבינות, יוגורט, חלב, משקה צמחי, לחם, דגנים, דגני בוקר, ירקות עמילניים, ירקות, פירות, אבוקדו, אגוזים, טחינה, שמן, קפה ותה.

אותו מסווג משמש בכל המערכת: בסיווג שורות הקבלה, במדד הבריאות, בבניית הסל, במתכנן ובוולידציה. כך מוצר נחשב לאותה קבוצה בכל שלב. מנגד, שגיאת סיווג אחת משפיעה על כל השלבים (סעיף 6.8).

### 6.2.2 תפקידי ארוחה

לכל קבוצה מוגדרות הארוחות שבהן היא משתלבת באופן טבעי.

|---|:-:|:-:|:-:|:-:|
| לחם, ביצים, גבינות, ירקות, אבוקדו | ✓ | ✓ | ✓ | |
| שמן, טחינה | ✓ | ✓ | ✓ | |
| בשר ועוף | | ✓ | | |
| דגים, קטניות, דגנים, ירקות עמילניים | | ✓ | ✓ | |
| יוגורט | ✓ | | ✓ | ✓ |
| דגני בוקר, חלב, משקה צמחי | ✓ | | | |
| פירות, אגוזים | ✓ | | | ✓ |
| קפה, תה | ✓ | | | ✓ |

שני חריגים: טופו וטונה מותרים גם בארוחת בוקר (טופו מוקפץ, טונה על לחם).

לכל מוצר נקבע גם סוג כשרות: בשרי (קבוצת הבשר והעוף), חלבי (גבינות, יוגורט, חלב) או פרווה.

### 6.2.3 חוקי הארוחה

ארוחה תקינה חייבת לקיים את כל החוקים הבאים. החוקים נבדקים בפונקציה אחת, המשמשת הן לסינון ארוחות מועמדות והן לוולידציה של התפריט המוגמר.

- אין בשר וחלב באותה ארוחה, ואין בשר ודג באותה ארוחה.
- חלבון עיקרי אחד בצלחת: לא יותר ממוצר אחד מקבוצות הבשר והדג, ולא קטניות לצד בשר או דג. שני מוצרי קטניות נחשבים צלחת טבעונית אחת.
- ארוחת צהריים וארוחת ערב כוללות מקור חלבון, וכן בסיס — פחמימה או ירק.
- כל מנה בין המינימום למקסימום הריאליים לקבוצתה. לדוגמה, התקרה לארוחה אחת: לחם 150 גרם, בשר 300 גרם, דגנים מבושלים 300 גרם, שמן 25 גרם, אגוזים 60 גרם, גבינה קשה 100 גרם. מנת בשר או דג בצלחת אינה קטנה מ-60 גרם.
- חלב או משקה צמחי מוגשים רק עם קפה, תה או דגני בוקר.
- ארוחת בוקר כוללת מזון ולא משקה בלבד; לכל היותר שני מזונות חלבון; ללא בשר או דג לצד דגני בוקר או יוגורט.
- ארוחת ביניים אינה כוללת לחם, דגנים, בשר, דגים, קטניות, שמן או ביצים.
- אין קפה בארוחת ערב.
- שם הארוחה בעברית, ואינו מזכיר מזון שאינו נמצא בה.

## 6.3 יצירת ארוחות מועמדות

### 6.3.1 תבניות

ארוחה מועמדת נוצרת מ**תבנית** — מבנה של ארוחה מקובלת — שמשבצותיה ממולאות במוצרי הסל המתאימים. לכל תבנית ערך ריאליזם קבוע בין 0 ל-1, המבטא עד כמה היא ארוחה יומיומית טבעית.

| ארוחה | תבנית | הרכב | ריאליזם |
|---|---|---|---|
| בוקר | לחם | לחם + גבינה / קוטג' / טופו + ירקות | 1.0 |
| בוקר | ביצים | ביצים (+ לחם) + ירקות | 1.0 |
| בוקר | דגני בוקר | דגני בוקר / שיבולת שועל + חלב + פרי | 0.95 |
| בוקר | יוגורט | יוגורט + פרי (+ אגוזים או שיבולת שועל) | 0.9 |
| בוקר | קוטג' ואבוקדו | גבינה + אבוקדו + ירקות (+ לחם) | 0.9 |
| בוקר | טונה | טונה + לחם + ירקות | 0.85 |
| בוקר (גיבוי) | לחם וממרח | לחם + ממרח (טחינה, חמאת בוטנים, אבוקדו) + ירקות | 0.85 |
| בוקר (גיבוי) | פרי ואגוזים | פרי + אגוזים (+ לחם) | 0.75 |
| צהריים / ערב | צלחת | בשר / דג / קטניות + פחמימה + ירקות (+ שמן או טחינה) | 1.0 |
| צהריים / ערב | צלחת חלבית | ביצים / גבינה / יוגורט + לחם + ירקות | 0.9 |
| צהריים / ערב (גיבוי) | צלחת פחמימה | פחמימה + ירקות, ללא חלבון | 0.4 |
| ביניים | פרי | פרי | 1.0 |
| ביניים | פרי ואגוזים | פרי + אגוזים | 0.95 |
| ביניים | יוגורט | יוגורט (+ פרי) | 0.9 |
| ביניים | אגוזים | אגוזים | 0.8 |

תבניות הגיבוי נוצרות רק כאשר הסל אינו מאפשר אף תבנית רגילה לאותה ארוחה. תפקידן להבטיח שכל יום יקבל את הארוחה, ושהמערכת תוכל להסביר מה חסר, במקום להיכשל ללא הסבר. צלחת ללא חלבון מקבלת ערך ריאליזם נמוך במכוון.

כאשר בסל יש קפה או תה, הם מצורפים לארוחות הבוקר, עם חלב אם יש.

### 6.3.2 מילוי התבניות

המועמדים נוצרים בלולאות מקוננות על מוצרי הסל המתאימים לכל משבצת בתבנית: לכל חלבון, לכל פחמימה, לכל זוג ירקות ולכל שומן. שלושה מנגנונים מגבילים את מספר הצירופים:

- לכל היותר שישה ירקות נלקחים בחשבון לארוחה, והם משובצים בזוגות מתחלפים (א-ב, ב-ג, ג-א) ולא בכל הצירופים האפשריים.
- ירקות תיבול — בצל, שום, עשבי תיבול — אינם משמשים כירק סלט.
- שתי ארוחות מאותו סוג בעלות אותם מוצרים נחשבות מועמד אחד.

המוצרים ממוינים לפי שם לפני יצירת המועמדים, ולכן סדר המועמדים קבוע.

### 6.3.3 מנות התחלתיות וסינון

לכל מוצר נקבעת מנה התחלתית לפי קבוצתו (למשל 100 גרם לחם, 200 גרם דגן מבושל, 120 גרם ירק, 150 גרם פרי). מנת החלבון העיקרי מחושבת כך שתספק את חלקה של הארוחה ביעד החלבון היומי, בין מינימום למקסימום ריאליים, מעוגלת ל-5 גרם. אלה נקודות מוצא בלבד; הכמויות הסופיות נקבעות באיזון המנות (סעיף 6.5).

לכל מועמד מחושבים הערכים התזונתיים והעלות לפי הכמויות ההתחלתיות. מועמד נשמר רק אם הוא עומד בכל חוקי הארוחה. לפיכך תזונה, אלרגיות, מזונות לא אהובים, כשרות ותפקידי ארוחה אינם חלק מהניקוד: ארוחה המפרה אותם אינה נוצרת כלל.

## 6.4 תהליך החיפוש / הבחירה

### 6.4.1 ניסוח הבעיה

יש לבחור ארוחה מועמדת אחת לכל אחת מ-28 המשבצות, כך שערך פונקציית המטרה השבועית יהיה מרבי. אם לכל סוג ארוחה C מועמדים, מספר התפריטים האפשריים הוא מסדר גודל של C בחזקת 28; חיפוש ממצה אינו מעשי, ולכן נעשה שימוש בחיפוש היוריסטי. האלגוריתם אינו מבטיח את התפריט הטוב ביותר האפשרי, אלא תפריט טוב העומד בבדיקות (סעיף 6.8).

### 6.4.2 פונקציית המטרה

  objective(week) = Σ scoreMeal(c) − weeklyPenalty(week)

הסכום הוא על כל הארוחות שנבחרו. הרכיב הראשון מעריך כל ארוחה בפני עצמה; השני מעריך את השבוע כמכלול, כך שבחירת ארוחה אחת "רואה" את כל האחרות.

**ציון הארוחה.** סכום משוקלל של הרכיבים הבאים. רכיבי הקרבה ליעד מחושבים כ-1 פחות הסטייה היחסית מהיעד, חסומים בין 0 ל-1.

| רכיב | מה נמדד | משקל |
|---|---|---|
| חלבון | חלק החלבון בקלוריות הארוחה מול חלקו ביעד היומי (לא בארוחת ביניים) | 3 |
| שומן | חלק השומן בקלוריות מול חלקו ביעד | 2 |
| ריאליזם | ערך הריאליזם של התבנית | 2 |
| מחיר | מחיר לקק"ל מול המחיר הטיפוסי בסל; 0.5 במחיר הטיפוסי | 1.5 |
| מחיר החלבון | מחיר לגרם חלבון של החלבון העיקרי מול הטיפוסי בסל | 1.5 |
| מוצר יקר | קנס לכל מוצר מהרבעון היקר ביותר בסל (לפי מחיר לקק"ל) | 1.5 |
| פחמימות | חלק הפחמימות בקלוריות מול חלקן ביעד | 1 |
| מזון אהוב | הארוחה כוללת מזון אהוב מהפרופיל | 1 |
| קלוריות | קלוריות הארוחה מול חלקה ביום | 0.5 |

המשקל הנמוך של רכיב הקלוריות מכוון: הכמויות מותאמות ממילא בשלב האיזון.

**הקנס השבועי.** סכום משוקלל של רכיבים המודדים חזרתיות, חריגה מתקציב וחוסר בחלבון.

| קבוצה | רכיב | משקל |
|---|---|---|
| תקציב | חריגת העלות המשוערת מעל התקציב | 40 |
| תקציב | לחץ עלות: ללא קנס עד 70% מהתקציב, מתון עד 85%, תלול מעבר לכך | 8 |
| תזונה | חוסר חלבון יומי מול היעד | 12 |
| תזונה | חלבון יומי מעל 115% מחלקו ביעד, או שומן בסטייה מעל 10% | 2 |
| גיוון חלבון | אותו חלבון עיקרי ביותר משלוש ארוחות צהריים | 6 |
| גיוון חלבון | ארוחת צהריים "קלה" (צלחת חלבית) יותר מפעם בשבוע, למי שאינו צמחוני | 6 |
| גיוון חלבון | חלבון אחד ביותר ממחצית הארוחות העיקריות | 3 |
| גיוון חלבון | אותו חלבון פעמיים ביום | 1.5 |
| גיוון חלבון | אותו חלבון באותה ארוחה בימים עוקבים | 0.8 |
| גיוון חלבון | פיזור: סכום ריבועי השימושים בכל חלבון | 0.35 |
| חזרת ארוחות | אותו "גרעין" (חלבון + פחמימה) פעמיים ביום | 3 |
| חזרת ארוחות | אותה ארוחה בדיוק שוב | 2 |
| חזרת ארוחות | אותה חתימה (תבנית + חלבון + פחמימה) בצהריים ובערב | 2 |
| חזרת ארוחות | מזון ליבה אחד ביותר מ-12 מתוך 21 הארוחות העיקריות | 2 |
| חזרת ארוחות | אותו גרעין בסוגי ארוחות שונים | 1 |
| חזרת ארוחות | אותה חתימה בארוחות הבוקר | 0.8 |
| גיוון כללי | סגנון ארוחת הבוקר, פחמימות, ירקות ופירות — סכום ריבועי השימושים | 0.25–0.6 |
| גיוון כללי | ירק או פרי שבסל ולא נעשה בו שימוש | 0.6 |

רכיבי "סכום הריבועים" מעודדים פיזור אחיד: שימוש בשני חלבונים שבע פעמים כל אחד עדיף על שימוש באחד שתים-עשרה פעמים ובשני פעמיים. רכיבי הגיוון מופעלים רק כאשר הסל מאפשר לקיימם — למשל, כלל שלוש ארוחות הצהריים חל רק אם בסל שלושה חלבונים לפחות המתאימים לצהריים.

אומדן העלות השבועית בקנס מחושב ממחיר לקק"ל של הארוחות שנבחרו, מוכפל בקלוריות השבוע ובמקדם 1.15, המשקף את תוספת העלות הנובעת מקניית אריזות שלמות.

[VERIFY: יש לברר מול אביעד ונועם כיצד נקבעו המשקלים. היסטוריית הגרסאות מעידה שכוונו במהלך סבבי QA; בהיעדר תיעוד מפורט יש להציגם כערכים שכוונו אמפירית.]

### 6.4.3 אלגוריתם החיפוש

**שלב א — בנייה חמדנית.** המשבצות ממולאות לפי הסדר, יום אחר יום וארוחה אחר ארוחה. לכל משבצת נבחר המועמד שממקסם את פונקציית המטרה בהינתן כל מה שנבחר עד כה.

**שלב ב — חיפוש מקומי בסדר קבוע.** עוברים על כל המשבצות באותו סדר. לכל משבצת נבדקים כל המועמדים, והמשבצת מוחלפת במועמד שמשפר את פונקציית המטרה של השבוע כולו במידה הרבה ביותר, אם יש כזה. המעבר חוזר עד שמעבר שלם אינו משנה דבר, ולכל היותר שישה מעברים.

```
תכנן_שבוע(מועמדים, הקשר):
    שבוע ← 7 ימים × 4 משבצות ריקות
    לכל יום, לכל משבצת:                               # בנייה חמדנית
        שבוע[יום][משבצת] ← המועמד שממקסם מטרה(שבוע)
    חזור עד 6 פעמים:                                   # חיפוש מקומי
        לכל יום, לכל משבצת:
            הטוב ← המועמד שממקסם מטרה(שבוע) במשבצת זו
            אם הטוב משפר את המטרה: החלף
        אם לא בוצעה החלפה במעבר: עצור
    החזר שבוע
```

**דטרמיניזם.** במקרה שוויון נשמר המועמד המוקדם בסדר היצירה, והשוואת הערכים נעשית עם סף קטן למניעת השפעה של שגיאות עיגול. אין בחירה אקראית ואין נקודת התחלה אקראית.

**סיבוכיות.** חישוב פונקציית המטרה ליניארי במספר המשבצות S = 28. בבנייה החמדנית ובכל מעבר של החיפוש המקומי נבדקים, לכל משבצת, C מועמדים. לכן סיבוכיות כל שלב היא O(S²·C), ו-C הוא לכל היותר מאות אחדות. [VERIFY: זמן הריצה בפועל לא נמדד; ראו סעיף 8.10.]

### 6.4.4 ארבע גרסאות וניסיון נוסף

חיפוש מקומי נעצר במקסימום מקומי, התלוי במשקלים. כדי לא להסתמך על כיול יחיד, המתכנן מורץ ארבע פעמים עם דגשים שונים:

| גרסה | השינוי במשקלים |
|---|---|
| מאוזנת | המשקלים הבסיסיים |
| חלבון תחילה | חוסר חלבון ×3, התאמת חלבון ×2; קנסות החזרה מופחתים ל-0.2 |
| תקציב תחילה | חריגת תקציב ×3; רכיבי המחיר ×2 |
| גיוון תחילה | קנסות החזרה והגיוון ×3 |

כל אחד מארבעת השבועות עובר את יתר שלבי השרשרת — איזון, התאמה לתקציב וולידציה — ורק אז נבחר הטוב ביותר. ההשוואה נעשית אפוא על התפריט הסופי ולא על ערך פונקציית המטרה, משום שרק לאחר האיזון ידועים החלבון והעלות בפועל. סדר ההכרעה:

1. רמת האיכות הנמוכה ביותר (סעיף 6.7);
2. מספר הבדיקות שנכשלו;
3. מדד הגיוון הגבוה ביותר;
4. חריגת העלות מעל 85% מהתקציב;
5. מספר הבדיקות ה"מוגבלות";
6. העלות.

העלות מכריעה רק מעל 85% מהתקציב: מתחת לסף זה המרווח מנוצל לגיוון ולא לחיסכון נוסף.

## 6.5 איזון מנות ומאקרו

החיפוש בוחר *אילו* ארוחות ייאכלו. איזון המנות קובע *כמה* מכל מוצר, כך שכל יום יעמוד ביעדיו.

### 6.5.1 ערכים תזונתיים

הערכים ל-100 גרם של כל מוצר נלקחים מהסל (שמקורם בקטלוג) כאשר הם סבירים, ואחרת מערכי ייחוס. הבדיקה נעשית מול טווחי סבירות של קלוריות ושל חלבון לכל קבוצת מזון; למשל, ערך של 8 גרם חלבון ל-100 גרם לדג נפסל. ערכי הייחוס מוגדרים לכל קבוצה, עם ערכים מיוחדים למוצרים כגון גבינה קשה, טופו, טונה וסלמון. [VERIFY: מקור ערכי הייחוס וטווחי הסבירות אינו מצוין בקוד; יש לברר ולצטט.]

המנות בתפריט הן "כפי שנאכל". דגנים וקטניות יבשים מומרים למשקל מבושל במקדמים 2.7 ו-3 בהתאמה, פרט למוצרים מוכנים לאכילה כגון טופו וקטניות משומרות.

### 6.5.2 סדר העדיפויות

כאשר לא ניתן לקיים את כל היעדים בו-זמנית, סדר העדיפויות הוא:

  **קלוריות ← חלבון ← שומן ← פחמימות**

- היעד **הקלורי** הוא האילוץ המחייב.
- **החלבון** קודם לפחמימות: כאשר הגעה ליעד החלבון מחייבת מקום בתקציב הקלורי, מנות הפחמימה מוקטנות — גם מתחת למינימום הרגיל שלהן, ואף מוסרות מצלחת שיש בה ירקות. מנות חלבון לעולם אינן מוגדלות רק כדי להשלים קלוריות.
- **השומן** הוא יעד רך יותר: חריגה כלפי מעלה מטופלת, ואילו ערך נמוך מהיעד מתקבל בטווח רחב.
- **הפחמימות** סופגות את ההפרש. יעד הפחמימות מדווח אך אינו נאכף.

### 6.5.3 שלבי האיזון

האיזון נעשה לכל יום בנפרד, במעבר אחד בסדר קבוע, ואחריו שלב סגירה.

1. **חלבון** — הבאת החלבון היומי לטווח של כ-90% עד 110% מהיעד: מתחת לטווח מוגדלות מנות החלבון הקיימות (עד התקרה הריאלית) ומוקטנות מנות פחמימה ושומן; מעל הטווח מוקטנות מנות החלבון, והקלוריות מוחזרות לפחמימות.
2. **שומן** — אם השומן מעל 115% מהיעד, מוקטנות מנות השמן, הטחינה והאגוזים.
3. **קלוריות** — בחוסר: הגדלת מנות הפחמימה של היום, לאחר מכן הוספת תוספת פחמימה ממוצר שכבר בשימוש בתפריט, ורק אם עדיין חסר — שומן. בעודף: הקטנת תוספות שומן ואחריהן פחמימות.
4. **תיקון** — אם הגדלת הלחם העלתה את החלבון מעל 110%, מנות החלבון מוקטנות פעם אחת.

**שלב הסגירה** חוזר עד שש פעמים על מדידה, בחירת מה לשנות ושינוי הכמויות, ומכוון את הקלוריות לסטייה של עד ±1% מהיעד. יום נחשב תקין בשלב זה כאשר מתקיימים כל התנאים:

- קלוריות בטווח **±3%** מהיעד;
- חלבון בין 90% ל-110% מהיעד;
- שומן בין 75% ל-115% מהיעד;
- אף מנה אינה חורגת מהתקרה הריאלית.

חריג אחד: כאשר הסל אינו יכול לספק 90% מיעד החלבון גם במנות מלאות, היום מתקבל ברמת החלבון הגבוהה ביותר שניתן להגיע אליה, והמגבלה מדווחת. יום שאינו עומד ביעד שומר על גרסתו הטובה ביותר, והחריגה נרשמת עליו ומוצגת למשתמש עם המספרים בפועל.

מנות ירקות, קפה ותה אינן משתנות באיזון: תרומתן הקלורית זניחה וגודלן נקבע לפי הרגל.

## 6.6 התאמה לתקציב

התקציב משפיע על התפריט בשלושה שלבים.

1. **בחיפוש** — דרך רכיבי המחיר בציון הארוחה ורכיבי התקציב והעלות בקנס השבועי (סעיף 6.4.2).
2. **לאחר האיזון** — בדיקת עלות אמיתית. עלות התפריט מחושבת בדיוק כפי שתחושב רשימת הקניות הסופית: צריכה שבועית לכל מוצר, המרה לכמויות קנייה ותמחור (פרק 7). אם העלות גבוהה מהתקציב, מבוצעות החלפות:
   - המוצרים היקרים ביותר נבדקים תחילה;
   - מוצר מוחלף, ארוחה אחת בכל פעם, במוצר זול יותר מהסל **מאותו סוג**: חלבון בחלבון תוך שמירה על גרמי החלבון; פחמימה, שומן ופרי תוך שמירה על הקלוריות; ירק תוך שמירה על המשקל;
   - ההחלפה חייבת לשמור על אופי הארוחה (צלחת חלבון נשארת צלחת חלבון) ועל כל חוקי הארוחה;
   - לאחר ההחלפה היום מאוזן מחדש ליעדיו;
   - ההחלפה נשמרת רק אם העלות האמיתית של השבוע ירדה ב-0.5 ₪ לפחות.

   מספר ההחלפות מוגבל ל-40.
3. **בבחירת השבוע** — העלות היא אחד ממפתחות ההכרעה בין ארבע הגרסאות (סעיף 6.4.4).

לאחר ההתאמה מופעלת רשת ביטחון של חוקי הארוחה: התפריט נבדק שוב, ואם נמצאה הפרה מופעל תיקון כפוי. עלות התפריט מחושבת פעם נוספת לאחר התיקון, כך שהעלות הנשמרת היא עלות התפריט כפי שנשמר.

אם התפריט נותר מעל התקציב גם לאחר ההחלפות, הוא אינו מוסתר: החריגה נרשמת, משפיעה על רמת האיכות (סעיף 6.7), ומוצגת למשתמש יחד עם הצעה לחלופות זולות יותר בסל.

## 6.7 ולידציה ורמות איכות

### 6.7.1 מערכת הוולידציה

כל תפריט נבדק במודול מרכזי אחד, נפרד מהמתכנן. ההפרדה מכוונת: המתכנן מנסה למקסם פונקציית מטרה, ואילו הוולידטור בודק את התוצאה באופן בלתי תלוי מול הדרישות, ואינו מניח שהמתכנן הצליח. אותו ולידטור בודק כל תפריט, בין שנבנה זה עתה ובין שנטען מהשרת.

הבדיקות מחולקות לשישה תחומים.

| תחום | הבדיקות |
|---|---|
| כיסוי | בסל יש חלבון לארוחה עיקרית, פחמימה, ירקות ומשהו לארוחת בוקר |
| בטיחות | כל מוצרי התפריט קיימים בסל; אין מוצר שאינו מזון; אין אלרגן או הפרת תזונה; אין בשר וחלב באותה ארוחה |
| ריאליזם | כל הארוחות עומדות בחוקי הארוחה ובגודל מנה ריאלי; שבעה ימים עם שלוש ארוחות לפחות; ארוחת בוקר, צהריים וערב בכל יום |
| תזונה | בכל יום: קלוריות בטווח **±5%** מהיעד; חלבון 90% מהיעד לפחות; שומן בין 75% ל-115% מהיעד |
| תקציב | עלות התפריט שווה לעלות רשימת הקניות הסופית; העלות אינה עולה על התקציב |
| גיוון | אותו חלבון עיקרי בלא יותר משלוש ארוחות צהריים; אף חלבון ביותר ממחצית הארוחות העיקריות; שלושה מקורות חלבון לפחות; ארוחת הבוקר אינה זהה בכל יום; תחלופת פחמימות, ירקות ופירות; אותה ארוחה לא יותר משלוש פעמים; אותה ארוחה אינה חוזרת בסוגי ארוחות שונים; אף מזון ליבה ביותר מ-12 מתוך 21 הארוחות העיקריות |

יעד הפחמימות נבדק בטווח ±25% ומדווח, אך אינו נכלל בדירוג, משום שהאיזון אינו מכוון אליו.

### 6.7.2 שני ספי הקלוריות

במערכת קיימים שני ספים שונים לסטייה מהיעד הקלורי, ולכל אחד תפקיד אחר:

| | סף | תפקיד |
|---|---|---|
| איזון המנות (שלב הסגירה) | ±3%, בכיוון ל-±1% | הערך שהאלגוריתם שואף אליו בעת קביעת הכמויות |
| ולידציה | ±5% | הערך שמתחתיו התפריט נחשב עומד ביעד בדירוג האיכות |

האיזון מחמיר מהוולידציה. המרווח בין השניים משמש כשולי ביטחון: שלבים מאוחרים לאיזון — החלפות התקציב ותיקון חוקי הארוחה — עשויים לשנות מעט את הכמויות, ויום שאוזן ל-±3% נשאר לרוב בתוך ±5% גם לאחריהם. [VERIFY: ההסבר למרווח הוא פרשנות של מבנה הקוד; יש לאשר מול אביעד ונועם שזו הייתה הכוונה.]

הבדל דומה קיים ביעד השומן: בדיווח הביניים של האיזון מסומן יום שבו השומן מחוץ לטווח 85%–115%, ואילו כלל הקבלה הסופי, בשלב הסגירה ובוולידציה, הוא 75%–115%.

### 6.7.3 "מוגבל" לעומת "נכשל"

בדיקות הגיוון נשפטות מול מה שהסל מאפשר. אם הסל כולל רק שני מקורות חלבון לצהריים, אין אפשרות ששבע ארוחות צהריים יכילו כל חלבון שלוש פעמים לכל היותר. במקרה כזה הבדיקה אינה מסומנת כנכשלת אלא כ**מוגבלת**: החזרה נובעת מהסל ולא מכשל של המתכנן. ההבחנה משפיעה על ההסבר למשתמש: במקום "התפריט אינו מגוון" מוצגת המלצה קונקרטית מה להוסיף לסל.

### 6.7.4 רמות האיכות

| רמה | תנאי | התנהגות המערכת |
|---|---|---|
| 1 | כל הבדיקות עברו, ללא בדיקות מוגבלות | התפריט מוצג |
| 2 | בדיקת גיוון נכשלה, או שיש בדיקה מוגבלת | התפריט מוצג, עם הסבר על הגיוון המוגבל |
| 3 | בדיקת תזונה או תקציב נכשלה | התפריט מוצג, עם הודעה מפורשת שאינו עומד בכל היעדים, ופירוט מה חסר |
| 4 | בדיקת כיסוי, בטיחות או ריאליזם נכשלה | **התפריט אינו נשמר ואינו מוצג**; מוצגת שגיאה המסבירה מה לא תקין ומה להוסיף לסל |

הרמה נקבעת לפי התחום החמור ביותר שבו נכשלה בדיקה. לצד הרמה מחושב **מדד גיוון** בין 0 ל-1, המשקלל את מספר הארוחות העיקריות השונות, ארוחות הבוקר, החלבונים, הפחמימות, הירקות והפירות — כל אחד ביחס למה שהסל מאפשר. המדד משמש להשוואה בין שבועות.

בנוסף לרמה 4, תפריט שבאחד מימיו חסרה ארוחת בוקר, צהריים או ערב נדחה בשגיאה ייעודית, המציינת איזו ארוחה חסרה ואילו סוגי מוצרים נדרשים לה.

העיקרון המנחה הוא שתפריט המוצג למשתמש הוא תפריט קביל, או שהמסך אומר במפורש שאינו כזה. התפריט אינו מוצג לעולם כתקין כאשר אינו עומד ביעד.

תוצאת הוולידציה מוצגת למשתמש ב"כרטיס איכות התפריט", המנסח בעברית את הממצאים: מה תקין, מה מוגבל ומדוע, ואילו מוצרים כדאי להוסיף לסל.

### 6.7.5 בנייה מחדש ותפריטים חלופיים

המשתמש יכול לבקש תפריט אחר ("בנייה מחדש"). מאחר שהמתכנן דטרמיניסטי, בנייה חוזרת פשוטה הייתה מחזירה את אותו תפריט. לכן הוגדר מנגנון חלופות דטרמיניסטי:

- **רשימת החלופות** כוללת את השבוע הטוב ביותר, ואחריו, בסדר קבוע, את תוצאות הגרסאות האחרות: גיוון, תקציב, חלבון ומאוזנת. כאשר מתבקשת בנייה מחדש נוסף ניסיון חמישי: שבוע המתוכנן הרחק מארוחות השבוע הטוב ביותר, באמצעות קנס על כל גרעין ארוחה שכבר הופיע בו.
- **קבילות.** חלופה נכללת רק אם אינה ברמה 4 ואינה גרועה מהשבוע הטוב ביותר בתזונה או בתקציב.
- **שוני.** שני תפריטים נחשבים שונים כאשר לפחות 25% ממשבצות הבוקר, הצהריים והערב שלהם בנויות סביב גרעין אחר (חלבון עיקרי ופחמימה). חלופה שהיא כמעט העתק של תפריט שכבר ברשימה אינה נכללת.
- **מעבר.** מזוהה מיקומו של התפריט המוצג ברשימה, ומוחזרת החלופה הבאה אחריו, במעגל. הרשימה נבנית תמיד מהשבוע הטוב ביותר ולא מהתפריט שעל המסך, ולכן היא זהה בכל לחיצה, והלחיצות עוברות עליה לפי הסדר.
- **מיצוי.** כאשר אין חלופה השונה מספיק מהתפריט המוצג, המערכת מודיעה שזהו התפריט היחיד שניתן לבנות מהסל הנוכחי בלי ארוחות לא מציאותיות. כפתור הבנייה מחדש מוצע רק כאשר קיים תפריט תקין אחר.

## 6.8 מגבלות

1. **היוריסטיקה ולא אופטימיזציה.** חיפוש חמדני וחיפוש מקומי אינם מבטיחים את התפריט הטוב ביותר האפשרי. הרצת ארבע גרסאות מפחיתה את התלות בכיול יחיד, אך אינה מבטלת אותה. פתרון מדויק, למשל בתכנות בשלמים, לא מומש (סעיף 9.4).
2. **סיווג לפי מילות מפתח.** קבוצת המזון נקבעת מהופעת מונח בשם המוצר. שגיאת סיווג משפיעה על תפקידי הארוחה, על חוקי הכשרות ועל ערכי הייחוס התזונתיים. דוגמה שתוקנה היא מוצרי דגנים שסווגו כדג (סעיף 4.7). דוגמאות שנותרו: דג משומר בשמן שאינו טונה, סרדינים או מקרל מסווג כשמן במסווג הכללי (בבניית הסל נוזל השימור מוסר מהשם לפני הסיווג), ודגני בוקר ממותקים ששמם כולל "פירות" מסווגים כפרי.
3. **ערכים תזונתיים מקורבים.** כאשר ערכי הקטלוג חסרים או אינם סבירים, נעשה שימוש בערכי ייחוס לקבוצת המזון. הערכים היומיים המוצגים הם לפיכך אומדן.
4. **תבניות ארוחה קבועות.** התפריט מוגבל לתבניות שהוגדרו, המשקפות ארוחות מקובלות בישראל. ארוחות מורכבות, מתכונים ומנות מעורבות אינם נתמכים.
5. **כשרות חלקית.** נאכפת הפרדה בין בשר לחלב ובין בשר לדג בתוך ארוחה בלבד. אין התייחסות להמתנה בין ארוחות או לכשרות המוצר עצמו.
6. **יעד הפחמימות אינו נאכף.** הוא מדווח בלבד.
7. **תלות בסל.** התפריט אינו יכול להיות טוב מהסל. סל ללא מקורות חלבון מספיקים יניב תפריט ברמה 3 לכל היותר. המערכת מתמודדת עם כך בשלב הסל (סעיף 5.5.5) ובהסבר למשתמש, ולא בהוספת מוצרים לתפריט.
8. **יעדי קלוריות גבוהים.** בתרחיש עלייה במשקל (3,417 קק"ל) הושג היעד באמצעות צבירת תוספות פחמימה באותה ארוחה, והתפריט דורג ברמה 2. באחד משבעת ימיו נותרה סטייה של 3.4% מהיעד — מעבר לסף האיזון ובתוך סף הוולידציה (סעיף 8.6).
9. **תקציב הדוק.** הסל נבדק מול תקציב המזון לפי אריזה אחת מכל מוצר, ואילו התפריט הנבנה ממנו עשוי לעלות יותר. במקרה כזה התפריט מדורג ברמה 3 והחריגה מוצגת, אך אינה נמנעת מראש (סעיף 8.7).
